# 5 分钟汇报：Tree of Thoughts 复现（负结果）

> 按任务书第 10 节模板。总时长 ~5 分钟，每节标注预算，超时先砍"差在哪"的细节。
> 一句话贯穿全场：**机制复现成功，结论方向反转，证据链完整。**

## 1. 论文一句话（30s）

Tree of Thoughts（NeurIPS'23）解决的是"自回归模型只能从左到右生成、无法回溯"的问题：把解题拆成树，每个节点生成多个候选思路、打分、保留最好的 b 条继续搜。
论文的招牌数字：Game of 24，GPT-4 用 CoT 只有 **4%**，用 ToT 到 **74%**。

## 2. 核心模块：当场画个示意（30s）

（白板画三层树：根节点=题目 → 每层画 3 个节点 → 边说边划掉被剪的）

```
  [4 9 10 13]
   /   |   \
 4+9  10-4  13-9     ← propose 生成 ~5 个候选
  ✓    ✗     ✓       ← value 打分(sure/likely/impossible)，只留 b=3
```
两个核心模块一句话各一：
- **BFS 搜索**（bfs.py `solve()`）：逐层扩展，贪心留 b 个，剪掉的永不复活
- **状态打分**（`get_value`）：把剩余数字喂给模型猜"离 24 多近"，三档映射成 {0.001, 1, 20}

## 3. 我复现的数字（60s）

| 口径 | 论文（GPT-4-0613，100 题） | 我（glm-5.3-flash，15 题 900-914） |
|---|---|---|
| CoT 逐样本 | 4.0% | **84.0%**（1260/1500） |
| CoT best-of-100 | 49% | **100%**（15/15） |
| ToT 每题 | 74%（b=5, e=3） | **40.0%**（6/15，b=3, e=1） |

设置：官方仓库 + 官方 24.csv 原题；CoT 每题 100 样本；ToT 每题目 1 次完整搜索；temperature 0.7；纯 API（无 GPU）。**方向反了：CoT 反超 ToT 44+ 个百分点。**

## 4. 差在哪：负结果归因（90s，可压缩到 60s）

排查链（任务书 6.1 顺序）：数据=官方原题 ✓；评测=`test_output` 一行未改 ✓；实现=ToT 全链路在 911 题上验证 r=1 ✓；超参=差异已声明（b=3/e=1 只会削弱 ToT，解释不了 baseline 从 4% 变 84%）。

剩下的原因（递进讲）：
1. **搜索被内化了**——抓取 glm 的隐藏推理流（reasoning_content），一条 CoT 样本里模型自己试了 5 条路、因"数字没用完"自我推翻 2 次。ToT 外部搜索干的事，2026 年的模型单次调用里自带。
2. **价值模型误剪**——900 题 CoT 99/100 对、ToT 却 0/3 全灭。value 模型"只会猜不会算"（三档打分，官方自注 ad hoc），每剪一次错就永久损失。
3. 配置弱化 b=3/e=1 是 ToT 只有 40% 的部分原因，不是反转原因。

结论：**机制成立（40% 与论文同构），"ToT 优于 CoT"的结论不迁移**——它依赖"基线很弱"这个前提。

## 5. Debug 一例（45s）

**现象**：911 题搜索明明找到了正确解，判定却 r=0。
**定位**：单题复跑 + 对照官方 gpt-4 日志 → 正确轨迹必须以 `Answer: ((1+8)+2)+13 = 24` 结尾；官方靠 game24.py 里"剩 24 就切 CoT 提示"的特判引出这行，而我们的输出过滤把 Answer 行当垃圾丢了。
**根因**：**理解错误**——改过滤规则前没先读判定函数 test_output 的契约（只看最后一行 + 数字多重集合 + sympy）。
**修法**：过滤放行 answer 开头行 → 重跑 r=1。（Agent 帮：写对照脚本找格式差异；Agent 坑：一开始主张整段搜 "=24"，会引入中间步骤误报。）

## 6. Agent 审计：它在哪里骗了我（45s）

**"BFS 实验已启动，正在后台跑"**——进程活着，一个请求都没发出去。
发现方式：proxy.log 长时间零流量 + `/proc/PID/environ` 里没有 API key。
真相：`wsl.exe bash -c` 非交互不加载 .bashrc，SDK 没 key 就静默回退 api.openai.com 无限重试。
教训：**后台任务"已启动"≠"在跑"**，30 秒内看到第一批网关请求才算数。（另有统计脚本 11/11 分母笔误一例，被列加和复核抓住——见 agent_log.md。）
